# Ferns and Petals (FNP) Sales Analysis using Excel

**Project Overview**

This project analyzes sales data from Ferns and Petals (FNP), a gifting company, using Microsoft Excel. The analysis focuses on understanding sales performance, customer purchasing patterns, product revenue, order occasions, and delivery timelines.

The workbook contains customer, order, and product datasets, along with summary tables used to examine key business metrics and support data-driven decision-making.

*Project Objectives*

Analyze overall sales revenue and order volume.
Identify monthly sales trends and revenue patterns.
Understand customer spending behavior.
Compare sales across different occasions.
Identify high-revenue products.
Analyze average order delivery time.
Explore customer and product data to identify useful business insights.

*Tools and Techniques*

Microsoft Excel
Pivot Tables and summary tables
Data aggregation and analysis
Sales performance analysis
KPI reporting
Dashboard-oriented business reporting
